# STS Technocrat ERP prototype

A working demo of the ERP designed for STS Technocrat (India) Pvt. Ltd.: enquiry → quotation → customer PO → purchase → raw materials → inventory → BOM → manufacturing → quality → dispatch → costing.

**Open it:** https://nishant-devekar.github.io/sts-technocrat-erp-prototype/

- One file (`index.html`), no server. Everything runs in your browser.
- Each tester gets a private practice copy saved in their own browser. Settings › Start again resets it.
- It's a demo, so documents it produces are marked "not a valid document".
